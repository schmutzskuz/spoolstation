# Crear un filamento

Antes de crear una bobina, el **filamento** correspondiente debe existir en Spoolman. Un filamento describe el tipo (fabricante, material, color, temperaturas); una bobina es una unidad concreta de él con un peso.

Los filamentos se crean en la **Biblioteca**. Haz clic arriba en **«Filamento»**. Hay dos formas.

## Desde la base de datos (recomendado)

SpoolStation conoce una gran base de datos de filamentos en línea (SpoolmanDB). Es la vía más rápida, porque las temperaturas, la densidad y el peso en vacío ya son correctos.

1. Elige la pestaña **«Desde base de datos»**.
2. Escribe el fabricante o el nombre en el buscador, p. ej. `Polymaker PLA` o `Prusament`.
3. Haz clic en la entrada correspondiente. Los campos se rellenan automáticamente.
4. Ajusta lo que necesites (p. ej. el color).
5. Haz clic en **«Crear filamento»** o **«Crear + añadir bobina»**.

## Crear manualmente

Si no encuentras tu filamento en la base de datos, créalo a mano:

1. Elige la pestaña **«Manual»**.
2. Introduce el **fabricante** (p. ej. `JAYO`). Si aún no existe, se crea automáticamente.
3. Introduce el **nombre**, el **material** (PLA, PETG …) y, opcionalmente, un **subtipo** (Mate, Silk …).
4. Elige un **color**. Para filamento multicolor puedes introducir varios colores.
5. Añade los ajustes de impresión (temperatura de boquilla y de cama), el diámetro, la densidad y el peso en vacío.
6. Haz clic en **«Crear filamento»**.

> Si ya existe un filamento con el mismo nombre y material, la app pregunta si quieres usar el existente. Así evitas duplicados.

Después puedes pasar directamente a [crear una bobina y escribir una etiqueta](chapter:write-tag).
